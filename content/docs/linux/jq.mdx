---
title: jq — JSON Processor
description: Command-line JSON parsing, filtering, and transformation.
---

## Basics

```bash
# Pretty print
echo '{"name":"John","age":30}' | jq .

# From file
jq . data.json

# From curl
curl -s https://api.example.com/user | jq .
```

## Accessing Fields

```bash
echo '{"name":"John","age":30}' | jq '.name'           # "John"
echo '{"name":"John","age":30}' | jq '.name, .age'     # multiple fields

# Nested access
echo '{"user":{"name":"John"}}' | jq '.user.name'

# Optional access (no error if missing)
echo '{}' | jq '.user.name?'                            # null (no error)
echo '{}' | jq '.user.name // "default"'                # "default" (with fallback)
```

## Raw Output

```bash
# Remove quotes from strings
echo '{"name":"John"}' | jq -r '.name'                  # John (no quotes)

# Raw input (treat each line as string)
echo -e "line1\nline2" | jq -R .
```

## Arrays

```bash
# Index
echo '[10,20,30]' | jq '.[0]'                          # 10
echo '[10,20,30]' | jq '.[-1]'                         # 30 (last element)

# Slice
echo '[10,20,30,40,50]' | jq '.[1:3]'                  # [20,30]

# Length
echo '[1,2,3,4]' | jq 'length'                         # 4

# Iterate all elements
echo '[1,2,3]' | jq '.[]'                              # outputs each on new line

# Get specific field from array of objects
echo '[{"name":"a"},{"name":"b"}]' | jq '.[].name'
echo '[{"name":"a"},{"name":"b"}]' | jq '[.[].name]'   # wrap back into array
```

## Filtering & Selecting

```bash
# Select from array
cat users.json | jq '.[] | select(.age > 25)'
cat users.json | jq '[.[] | select(.role == "admin")]'

# Multiple conditions
cat users.json | jq '.[] | select(.age > 25 and .active == true)'

# Contains
cat data.json | jq '.[] | select(.name | contains("John"))'

# Starts/ends with
cat data.json | jq '.[] | select(.email | endswith("@gmail.com"))'
```

## Transforming

```bash
# Construct new objects
cat data.json | jq '{id: .user_id, full_name: (.first + " " + .last)}'

# Map over array
echo '[1,2,3]' | jq '[.[] * 2]'                        # [2,4,6]
echo '[1,2,3]' | jq 'map(. * 2)'                       # same thing

# Add new field
cat users.json | jq '.[] | . + {"status": "active"}'

# Remove field
echo '{"a":1,"b":2,"c":3}' | jq 'del(.b)'             # {"a":1,"c":3}

# Rename keys
cat data.json | jq '{new_name: .old_name, new_age: .old_age}'
```

## Aggregation

```bash
# Count
cat items.json | jq 'length'

# Sum
echo '[1,2,3,4,5]' | jq 'add'                          # 15

# Min / Max
echo '[3,1,4,1,5]' | jq 'min'                          # 1
echo '[3,1,4,1,5]' | jq 'max'                          # 5

# Group by
cat users.json | jq 'group_by(.role) | map({role: .[0].role, count: length})'

# Sort
cat users.json | jq 'sort_by(.age)'
cat users.json | jq 'sort_by(.age) | reverse'

# Unique
echo '["a","b","a","c"]' | jq 'unique'                 # ["a","b","c"]
```

## Keys & Types

```bash
echo '{"a":1,"b":2}' | jq 'keys'                       # ["a","b"]
echo '{"a":1,"b":"x"}' | jq 'to_entries'               # [{key,value},...]
echo '[{"key":"a","value":1}]' | jq 'from_entries'     # {"a":1}

# Type checking
echo '{"a":1}' | jq '.a | type'                        # "number"

# Has key
echo '{"a":1}' | jq 'has("a")'                         # true
```

## String Operations

```bash
# Split
echo '"hello world"' | jq 'split(" ")'                 # ["hello","world"]

# Join
echo '["a","b","c"]' | jq 'join(",")'                  # "a,b,c"

# String interpolation
echo '{"name":"John","age":30}' | jq '"\(.name) is \(.age)"'

# Regex match
echo '"hello123"' | jq 'test("[0-9]+")'                # true
echo '"2024-01-15"' | jq 'capture("(?<y>[0-9]{4})-(?<m>[0-9]{2})")'
```

## Slurp & Multiple Inputs

```bash
# Slurp: read multiple JSON values into one array
cat lines.jsonl | jq -s '.'                            # array of all objects

# Slurp + process
cat lines.jsonl | jq -s 'map(.value) | add'

# Compact output (single line)
echo '{"a": 1}' | jq -c .                              # {"a":1}
```

## Real-World Recipes

```bash
# Parse docker ps JSON
docker inspect $(docker ps -q) | jq '.[].NetworkSettings.IPAddress'

# Extract from AWS CLI
aws ec2 describe-instances | jq '.Reservations[].Instances[] | {id: .InstanceId, state: .State.Name}'

# Transform API response for CSV
curl -s https://api.example.com/users | jq -r '.[] | [.name, .email, .role] | @csv'

# Merge two JSON files
jq -s '.[0] * .[1]' defaults.json overrides.json

# Pretty print with sorted keys
jq -S . messy.json > clean.json

# Diff two JSON files (structural)
diff <(jq -S . a.json) <(jq -S . b.json)

# ENV to JSON
env | jq -R 'split("=") | {(.[0]): .[1:] | join("=")}' | jq -s 'add'
```

## Useful Flags

| Flag | Purpose |
|------|---------|
| `-r` | Raw output (no quotes on strings) |
| `-R` | Raw input (treat input as strings) |
| `-c` | Compact output |
| `-s` | Slurp (read all into array) |
| `-S` | Sort keys |
| `-e` | Exit with error if output is null/false |
| `--arg name val` | Pass string variable into filter |
| `--argjson name val` | Pass JSON variable into filter |

```bash
# Using variables
jq --arg name "John" '.[] | select(.name == $name)' users.json
jq --argjson min 25 '.[] | select(.age > $min)' users.json
```
