## sed — Stream Editor

`sed` transforms text line-by-line. Think find-and-replace on steroids.

### Substitution (Most Common)

```bash
sed 's/old/new/' file.txt               # replace first occurrence per line
sed 's/old/new/g' file.txt              # replace ALL occurrences per line
sed 's/old/new/gi' file.txt             # global + case-insensitive
sed 's/old/new/2' file.txt              # replace only 2nd occurrence per line
```

### In-Place Editing

```bash
sed -i 's/old/new/g' file.txt           # Linux: edit file directly
sed -i '' 's/old/new/g' file.txt        # macOS: requires empty string for backup
sed -i.bak 's/old/new/g' file.txt       # create backup before editing
```

### Line Selection

```bash
sed -n '10p' file.txt                   # print only line 10
sed -n '10,20p' file.txt                # print lines 10-20
sed -n '/error/p' file.txt              # print lines matching pattern
sed '5d' file.txt                       # delete line 5
sed '1,3d' file.txt                     # delete lines 1-3
sed '/^#/d' file.txt                    # delete comment lines
sed '/^$/d' file.txt                    # delete empty lines
```

### Insert & Append

```bash
sed '3i\New line above 3' file.txt      # insert before line 3
sed '3a\New line below 3' file.txt      # append after line 3
sed '1i\#!/bin/bash' script.sh          # add shebang at top
```

### Using Different Delimiters

When your pattern contains `/`, use a different delimiter:

```bash
sed 's|/usr/local/bin|/opt/bin|g' file.txt
sed 's#http://#https://#g' file.txt
```

### Multiple Operations

```bash
sed -e 's/foo/bar/g' -e 's/baz/qux/g' file.txt
# or
sed 's/foo/bar/g; s/baz/qux/g' file.txt
```

### Capture Groups

```bash
# Swap first and last name
echo "John Smith" | sed 's/\(.*\) \(.*\)/\2 \1/'       # Smith John

# Add quotes around words
echo "hello world" | sed 's/\b\w\+\b/"&"/g'

# Extract version number
echo "v2.4.1" | sed 's/v\([0-9]*\)\.\([0-9]*\).*/\1.\2/'   # 2.4
```

### Real-World sed

```bash
# Remove trailing whitespace
sed 's/[[:space:]]*$//' file.txt

# Convert DOS line endings to Unix
sed 's/\r$//' file.txt

# Comment out a line containing a pattern
sed '/DISABLED/s/^/#/' config.txt

# Uncomment lines
sed 's/^#//' file.txt

# Replace between two markers
sed '/START/,/END/s/old/new/g' file.txt

# Print lines between two patterns
sed -n '/BEGIN/,/END/p' file.txt
```

## awk — Pattern-Action Processing

`awk` processes text as records (lines) split into fields (columns). It's a mini programming language.

### Basic Structure

```bash
awk 'pattern { action }' file
# If no pattern: action runs on every line
# If no action: prints matching lines
```

### Field Access

By default, fields are split on whitespace:

```bash
awk '{print $1}' file.txt               # first column
awk '{print $2, $4}' file.txt           # 2nd and 4th columns
awk '{print $NF}' file.txt              # last column
awk '{print $(NF-1)}' file.txt          # second-to-last column
awk '{print NR, $0}' file.txt           # line number + entire line
```

### Custom Delimiter

```bash
awk -F',' '{print $2}' data.csv         # comma-separated
awk -F':' '{print $1}' /etc/passwd      # colon-separated
awk -F'\t' '{print $3}' data.tsv        # tab-separated
```

### Pattern Matching

```bash
awk '/error/' app.log                   # lines containing "error"
awk '/^[0-9]/' file.txt                 # lines starting with digit
awk '$3 > 100' data.txt                 # 3rd field greater than 100
awk '$1 == "admin"' users.txt           # exact field match
awk 'NR >= 10 && NR <= 20' file.txt     # lines 10-20
awk 'NF > 0' file.txt                   # non-empty lines
```

### Built-in Variables

| Variable | Meaning |
|----------|---------|
| `$0` | Entire line |
| `$1`..`$N` | Nth field |
| `NR` | Current line number (across all files) |
| `NF` | Number of fields in current line |
| `FS` | Field separator (default: whitespace) |
| `OFS` | Output field separator |
| `RS` | Record separator (default: newline) |
| `ORS` | Output record separator |
| `FILENAME` | Current filename |

### BEGIN and END Blocks

```bash
# Header + footer
awk 'BEGIN {print "Name\tAge"} {print $1"\t"$2} END {print "---done---"}' data.txt

# Sum a column
awk '{sum += $1} END {print "Total:", sum}' numbers.txt

# Average
awk '{sum += $1; count++} END {print "Avg:", sum/count}' numbers.txt

# Count lines matching pattern
awk '/error/ {count++} END {print count}' app.log
```

### String Functions

```bash
# Length
awk '{print length($0)}' file.txt

# Substring
awk '{print substr($1, 1, 3)}' file.txt     # first 3 chars of field 1

# Find and replace (within awk)
awk '{gsub(/old/, "new"); print}' file.txt

# Split
awk '{split($1, arr, "-"); print arr[1]}' file.txt

# Uppercase / lowercase (gawk)
awk '{print toupper($1)}' file.txt
```

### Output Formatting

```bash
# Custom separator
awk -F',' 'BEGIN {OFS="\t"} {print $1, $2, $3}' data.csv

# Printf (C-style formatting)
awk '{printf "%-20s %10.2f\n", $1, $2}' data.txt
```

### Real-World awk

```bash
# Disk usage alert
df -h | awk '$5+0 > 80 {print "WARNING:", $6, "is", $5, "full"}'

# Top memory-consuming processes
ps aux | awk 'NR>1 {print $4, $11}' | sort -rn | head -10

# Parse access logs (count requests per IP)
awk '{print $1}' access.log | sort | uniq -c | sort -rn | head

# CSV to JSON-ish
awk -F',' 'NR>1 {printf "{\"name\":\"%s\",\"age\":%s}\n", $1, $2}' data.csv

# Sum file sizes in directory listing
ls -l | awk '/^-/ {sum += $5} END {printf "Total: %.2f MB\n", sum/1024/1024}'

# Print lines between patterns (exclusive)
awk '/START/{flag=1; next} /END/{flag=0} flag' file.txt

# Deduplicate lines (preserving order)
awk '!seen[$0]++' file.txt

# Multi-file processing
awk 'FNR==1 {print "--- " FILENAME " ---"} {print}' *.log

# Transpose columns to rows
awk '{for(i=1;i<=NF;i++) a[i]=a[i]" "$i} END {for(i in a) print a[i]}' file.txt
```

## When to Use Which

| Task | Best tool |
|------|-----------|
| Simple find/replace | `sed` |
| Delete/insert lines | `sed` |
| Column extraction | `awk` |
| Conditional logic on fields | `awk` |
| Aggregation (sum, count, avg) | `awk` |
| In-place file editing | `sed -i` |
| Complex multi-step transform | `awk` (or a script) |
| Pattern + replacement with groups | `sed` |
